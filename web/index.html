Sambungkan Supabase

Salin Project URL dan anon public key dari Supabase: Project Settings > API. Jangan pakai service_role key.

☁️ Cadangan data

Simpan salinan semua data Anda ke file, atau pulihkan dari file cadangan sebelumnya.

Pulihkan dari file

Pilih file cadangan-guru-….json. Data yang sudah ada tidak diubah dan tidak dihapus: hanya data yang belum ada yang ditambahkan.

📥 Impor nilai dari Excel

Kelas, jenis, tanggal, dan keterangan diambil dari formulir di halaman Nilai. File hanya mengisi kolom skor. Setelah itu Anda periksa, lalu klik Simpan Nilai.

File: .xlsx, .xls, atau .csv dengan kolom Nama Siswa dan Skor. Belum punya? Unduh template.

🛠️ Satu langkah di Supabase

Kolom keterangan belum ada di database Anda. Buka Supabase → SQL Editor, tempel kode ini, klik Run (sekali saja), lalu simpan nilai lagi.

✍️ Identitas & tanda tangan

Tampil di bagian bawah setiap dokumen yang dicetak. Data tersimpan di perangkat ini.
